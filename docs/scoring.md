# 스코어링 로직

## 가중치 (동적 조절 가능)

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 가속도 | 35% | 최근 3개월 vs 이전 3개월 평균가 변화율 |
| 환금성 | 25% | 해당 타입 거래건수 / 해당 타입 세대수 |
| 신축도 | 20% | 건축년도 기반 |
| 출퇴근 | 10% | 판교 출퇴근 평균 소요시간 |
| 소아과 | 10% | 도보거리 + 고저차 보정 |

- 각 항목은 전체 데이터에서 상대 순위(percentile rank)로 변환
- 출퇴근/소아과: 낮을수록 좋으므로 역순 랭킹
- `calcScores(data, weights)` — weights를 인자로 받아 동적 변경 가능
- 프론트엔드 슬라이더로 조절, localStorage에 저장

## 면적 타입 분류

| 타입 | 면적 범위 | 코드 |
|------|-----------|------|
| 소형 | 59~69㎡ | "59" |
| 중형 | 70~79㎡ | "74" |
| 국민평형 | 80~85㎡ | "84" |

`areaType(a)`: `a >= 80 ? "84" : a >= 70 ? "74" : "59"`

## 검색 (플로팅 Spotlight)

- 전체 데이터셋 대상 (필터 무관)
- 검색 필드: name, display_name, dong, doro_juso, region
- 필터 밖 아파트: disabled + 사유 표시 (빨간색)
- 선택 시: 테이블 행 스크롤 + 3초 하이라이트
- ⌘K 단축키, ESC 닫기, 150ms debounce

## Google Maps 지도

- Map ID: `2fc618fcc15fd5941df2ead6` (새 키용)
- `Map` import → `GoogleMap`으로 alias 필수 (JS `Map`과 충돌)
- 같은 아파트 여러 타입: 마커 1개, 툴팁에 모든 타입 표시
- 에러 바운더리: `MapErrorBoundary` 클래스
- viewMode는 localStorage에 저장하지 않음 (지도 크래시 방지)

## 구매 가능성 계산 (PricePopover)

- 취득세: 6억 이하 1%, 6~9억 누진, 9억 초과 3% + 교육세 10% + 농특세 20%(85㎡ 초과)
- 생애최초 감면: 200만원
- 대출: LTV 70% (최대 6억), DSR 40%
- 필요 자본금 = 매매가 + 세금 + 중개보수 - 최대대출
- 보유 금액 = 보유자본 + 추가대출 + 주담대 최대한도
